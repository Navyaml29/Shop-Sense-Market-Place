# ShopSense Admin - Marketplace Foundation

# About the project
ShopSense is a simple marketplace administration application built using Python and Streamlit. 
It provides a basic admin login page, CAPTCHA verification, and a vendor onboarding form.

# Features
- Admin login page
- Basic CAPTCHA verification
- Dashboard sidebar
- Vendor onboarding form
- Input validation
- Vendor status table

# Technologies Used
- Python
- Streamlit

# How to Run
1. Install Python.
2. Install Streamlit:
   pip install streamlit
3. Run the application:
   python -m streamlit run app.py

# Project Status
This is a learning project and a basic prototype. 
Vendor information is not permanently stored, and the login system is not intended for production use.
